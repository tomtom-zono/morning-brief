# 週刊誌スロット(仕様 3.2)

FACTA・選択・週刊ダイヤモンド(紙面)は日次自動化できないため、
このフォルダに読了メモを `.md` で置く。**ファイルが無い日は無視される。**

- 置いた翌朝の生成時に「今週の週刊誌視点」として各記事の拡張考察に織り込まれる
- ファイル名は自由(例: `2026-07-24-facta.md`)
- 読み終わって不要になったら削除してよい

## 書き方の例

```markdown
# FACTA 2026年8月号

## 記事タイトル
- 論点1: ...
- 論点2: ...
- 自分の見立て: ...
```

**注意**: 記事本文の書き写しではなく、要点と自分の見立てを書くこと。
本文をそのまま貼ると (1) DeepSeek API へ送信され、(2) 生成物が原文転載チェックに
抵触して再生成ループに入る可能性がある。
